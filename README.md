# SAM-LoRA for Remote Sensing Image Tampering Localization

Paper title: Dataset of RS-TID: A Remote Sensing Tampered Image Dataset for Multi-class Tampering Localization and Detection

Pixel-level remote sensing image tampering localization using the Segment Anything Model (SAM ViT-B) and LoRA. The model segments three types of tampered regions: copy-move, splicing, and removal.

LoRA adapters are inserted into the Q/V attention branches of the SAM image encoder. A full-image bounding box `[0, 0, W, H]` serves as the prompt, and a multiclass segmentation head predicts background and the three tampering classes. This repository provides training, dataset evaluation, and single-image inference scripts.

## Dataset and Pretrained Model

The dataset and SAM pretrained checkpoint are not included in this repository. Download them using the links below. **We do not release trained model weights.** Train the model yourself before running evaluation or inference.

| Resource | Download | Setup |
| --- | --- | --- |
| RS-TID dataset, including annotations and training/validation/test splits | [RS-TID](https://pan.baidu.com/s/1yY7O23Zs7wBUv_7pYkozng?pwd=4rps) (access code: `4rps`) | Extract to `all_dataset/`, or update the dataset paths in `config.yaml`. |
| Official SAM ViT-B pretrained checkpoint | [sam_vit_b_01ec64.pth](https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth) | Place it in the project root, or update `SAM.CHECKPOINT`. |

The official SAM checkpoint initializes the model. Follow the training instructions below to generate the LoRA parameters, classification head parameters, and checkpoints needed for evaluation and inference.

See the [official SAM repository](https://github.com/facebookresearch/segment-anything#model-checkpoints) for the checkpoint source and other model variants.

## Environment Setup

Run the following commands from the project root. Install mutually compatible PyTorch, TorchVision, and CUDA versions for your environment:

```bash
pip install torch torchvision
pip install numpy pillow pyyaml safetensors tqdm matplotlib seaborn monai
```

The repository includes `src/segment_anything/`; the main experiment does not require a separate installation of the `segment-anything` package.

Download the SAM ViT-B checkpoint:

```bash
curl -L https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth -o sam_vit_b_01ec64.pth
```

**Training device:** Both the classification head and training device in `train.py` currently use `cuda:1`, the second visible GPU. If only one GPU is visible, change both occurrences of `cuda:1` to `cuda:0`. Evaluation and single-image inference use `cuda` when available and otherwise use the CPU.

## Dataset Preparation

Download and extract the dataset using the link above. Preserve the provided `train/val/test` splits, with `images/` and `masks/` in each split. Use these splits for reproduction.

- Images and masks are paired by file stem, for example, `images/P1726.png` and `masks/P1726.png`.
- The loader supports JPG, JPEG, and PNG. Use lossless PNG for color annotations to preserve class colors.
- Masks are RGB images. The class mapping is defined in `src/utils.py`.

| Class ID | Class | RGB Color |
| --- | --- | --- |
| 0 | Untampered / background | Black `(0, 0, 0)` |
| 1 | copy_move (copy-move) | Green `(0, 255, 0)` |
| 2 | splicing | Red `(255, 0, 0)` |
| 3 | remove (removal) | Blue `(0, 0, 255)` |

The mask conversion function also maps white background `(255, 255, 255)` to class 0.

## Configuration

Update `config.yaml` to point to your local dataset and pretrained checkpoint. The current defaults are:

```yaml
DATASET:
  TEST_PATH: ./all_dataset/test
  TRAIN_PATH: ./all_dataset/train
  VAL_PATH: ./all_dataset/val
SAM:
  CHECKPOINT: ./sam_vit_b_01ec64.pth
  RANK: 512
TRAIN:
  BATCH_SIZE: 1
  GRADIENT_ACCUMULATION_STEPS: 16
  LEARNING_RATE: 1e-4
  NUM_EPOCHS: 50
  WEIGHT_DECAY: 0
```

The default effective batch size is `1 × 16 = 16`. The default random seed is 42; add `SEED` under `TRAIN` to override it. Early-stopping patience and other script settings are defined near the top of `train.py`.

## Training

After preparing the dataset, pretrained checkpoint, and device configuration, run:

```bash
python train.py
```

Training optimizes the image encoder's LoRA parameters and the multiclass segmentation head using a combination of Dice loss and class-weighted cross-entropy loss. The head uses two 3×3 convolutions, GroupNorm, GELU, dropout, and a residual branch.

Outputs are saved to `training_results/train_YYYYMMDD_HHMMSS/`:

| File | Contents |
| --- | --- |
| `config.yaml` | Configuration for the training run |
| `history.json` / `summary.json` | Training history and summary |
| `lora_rank{RANK}.safetensors` | LoRA parameters exported at the end of training |
| `multiclass_head.pth` | Classification head parameters exported at the end of training |
| `checkpoints/best_model.pth` | Full SAM state, including LoRA, classification head, and optimizer state at the lowest validation loss |

## Evaluation

Set the training result directory near the top of `evaluate_model_paper.py`:

```python
TRAINING_RESULT_DIR = "./training_results/train_YYYYMMDD_HHMMSS"
```

Ensure that the SAM checkpoint, LoRA rank, and dataset paths in `config.yaml` match the experiment, then run:

```bash
python evaluate_model_paper.py
```

By default, `USE_TEST_SET = True` selects the test set. With `LOAD_FROM_BEST_CHECKPOINT = True`, the script first attempts to load `checkpoints/best_model.pth`. If that file is unavailable, it loads `lora_rank{RANK}.safetensors` and `multiclass_head.pth` from the same training directory. These final exports may come from a different epoch than the best validation checkpoint.

Metrics are computed from a pixel confusion matrix accumulated over the entire evaluation set. Ground-truth masks are downsampled to the prediction resolution using nearest-neighbor interpolation, matching the training procedure. Both four-class macro averages (including background) and three-class macro averages (tampering only) are reported. Results are saved under `evaluation_paper/` in the training directory:

- `paper_summary.json`: Overall accuracy and macro-average Dice, IoU, and F1.
- `metrics_paper_ready.json`: Per-class and aggregate metrics.
- `confusion_matrix_raw.json`: Raw confusion matrix.
- `confusion_matrix_row_normalized.json`: Row-normalized confusion matrix.
- `confusion_matrix.png`: Confusion matrix visualization.

Report results with the corresponding training weights, dataset split, and evaluation settings.

## Single-Image Inference

Update the settings near the top of `test.py`:

```python
IMAGE_PATH = "./all_dataset/test/images/P1726.png"
CONFIG_FILE = "./config.yaml"
SAM_CHECKPOINT = "./sam_vit_b_01ec64.pth"
TRAINING_RESULT_DIR = "./training_results/train_YYYYMMDD_HHMMSS"
OUTPUT_DIR = "./test_results/single_image"
```

```bash
python test.py
```

Outputs include an RGB prediction mask and a visualization. Single-image inference primarily loads `lora_rank{RANK}.safetensors` and `multiclass_head.pth` from the training directory. Ensure both files come from the same run and epoch and match the configured rank. Unlike the evaluation script, this script does not directly restore the full best checkpoint.
